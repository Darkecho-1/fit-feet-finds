# FIT FEET FINDS

Telegram Mini App для магазина обуви. В одном проекте находятся витрина, панель управления, API и бот. Локальное демо работает на Node.js 24+ без внешней базы данных.

## Локальное демо

```powershell
npm.cmd run demo
```

Откройте [витрину](http://127.0.0.1:3000). Кнопка **Демо** переключает на владельца, кнопка **Витрина** возвращает на витрину. На широком экране они называются **Демо админки** и **Режим покупателя**. Оба режима используют один демо-склад в рамках браузера. При перезапуске сервера данные демо сбрасываются.

- В каталоге 25 карточек с фотографиями и исходными объявлениями из [канала FIT FEET FINDS](https://t.me/fit_feet_finds), плюс черновик в панели. Количества, заказы и доставка в демо условные.
- Карточку можно открыть сразу, например [Nike Shox TL](http://127.0.0.1:3000/?product=shox-blue). В карточке выберите размер и оформите заказ либо добавьте пару в корзину.
- В админке откройте заказ, проверьте резерв и обновите статус. Отмена возвращает пары на склад. Внешняя продажа списывает остаток и попадает в журнал. После закрытия или выдачи заказа доступна история.
- В разделе **Обзор → Редактировать дроп** выберите товар для главного баннера, заголовок и фото из карточки. Там же можно включить автоматический выбор доступной новинки или скрыть баннер.
- В заказе видны Telegram ID и юзернейм покупателя. Рабочая ссылка открывает чат с черновиком по номеру заказа. Без юзернейма бот может открыть профиль по ID, если это разрешают настройки Telegram.
- В разделе **Товары** можно скопировать ссылку, создать карточку, загрузить фото или задать HTTPS-ссылки, сохранить черновик, опубликовать или убрать карточку в архив. Из архива можно удалить карточку без связанных заказов и продаж.

## Бесплатный запуск на Cloudflare Workers

Витрина открывается по HTTPS на `workers.dev`. Cloudflare обслуживает статические файлы и Telegram webhook, а каталог, корзины, заказы, остатки и загруженные фотографии хранятся в SQLite Durable Object. В браузере доступен гостевой каталог. Для тестового заказа требуется аккаунт Telegram.

1. Войдите в Cloudflare и выполните `npm ci`, `npx wrangler login`, `npm run deploy`. Можно также подключить репозиторий в **Workers & Pages** и указать команду развёртывания `npm run deploy` с Node.js 24. Для проекта достаточно тарифа Workers Free.
2. В **Settings → Variables and Secrets** Worker добавьте переменную `PUBLIC_URL` с опубликованным HTTPS-адресом и секрет `BOT_TOKEN` с токеном из [BotFather](https://t.me/BotFather). `BOT_USERNAME` задаётся в `wrangler.jsonc` и должен совпадать с ботом. Worker подключает webhook и кнопку меню автоматически после добавления настроек. Готовность видна по `botReady` на `/health`.
3. Напишите боту `/id` и добавьте полученный номер как переменную `OWNER_ID` в тех же настройках Worker. Затем отправьте боту `/start` и откройте панель. Установить роль владельца можно только через конфигурацию серверной части.
4. В BotFather выберите бота, откройте **Bot Settings → Configure Mini App → Enable Mini App** и укажите тот же HTTPS-адрес как **Main Mini App**. После этого ссылки вида `https://t.me/имя_бота?startapp=p_товар` будут вести прямо к карточке товара.

Токен хранится в секретах Worker. Для локальной проверки используйте `npm run worker:dev` и отдельный файл `.dev.vars`, который исключён из Git. Для рабочего магазина можно поставить `PORTFOLIO_DEMO=0` перед первым запуском, заполнить свой каталог и настроить действующий Telegram-контакт менеджера. Переключение режима сохраняет ранее созданные данные.

[Документация Cloudflare Workers](https://developers.cloudflare.com/workers/get-started/guide/) · [Тариф SQLite Durable Objects](https://developers.cloudflare.com/durable-objects/platform/pricing/) · [Telegram Main Mini App](https://core.telegram.org/bots/webapps#launching-the-main-mini-app)

## Запуск на своём Node.js-сервере

1. Создайте бота в [BotFather](https://t.me/BotFather). Укажите публичный адрес приложения с HTTPS как **Main Mini App** либо зарегистрируйте приложение с коротким именем.
2. Скопируйте `.env.example` в `.env` и заполните `PUBLIC_URL`, `BOT_TOKEN`, `BOT_USERNAME` и числовой `OWNER_ID`. При использовании приложения с коротким именем заполните `APP_SHORT_NAME`. Храните `.env` на сервере.
3. Запустите `npm start` на сервере. Оставьте один экземпляр бота с long polling и направьте HTTPS-прокси на `HOST:PORT`. Укажите постоянную директорию `DATA_DIR` для SQLite и загруженных фотографий. Для первого запуска с примерами поставьте `IMPORT_DEMO_DRAFTS=1`. Карточки импортируются в черновики с нулевыми остатками.
4. Владелец и администраторы отправляют боту `/start`, чтобы открыть панель и получать оповещения. Сотрудники получают свой ID командой `/id`. Добавление и удаление администратора доступно владельцу в настройках команды.
5. После публикации карточки скопируйте её ссылку в панели и добавьте к посту. Telegram передаст параметр `startapp`, и приложение откроет этот товар. При первом прямом переходе покупатель может разрешить сообщения от бота в окне заказа или запустить бота через Start.

При оформлении заказ получает номер формата `FFF-…`. Трек-номер перевозчика указывает сотрудник после сборки и отправки. Оплата в приложении не списывается. В рабочем режиме оплату и доставку подтверждает менеджер. В настройках можно уточнить тарифы, способы доставки, условия заказа и Telegram-контакт менеджера.

Сервер проверяет подпись и время выпуска Telegram `initData`, назначает роли по Telegram ID и сохраняет заказы и изменения остатков транзакциями SQLite. Уведомления о заказах и напоминания обрабатываются через очередь. Напоминания отключаются в панели или командами `/reminders_on` и `/reminders_off`.

[Документация Telegram Mini Apps](https://core.telegram.org/bots/webapps) · [Ссылки на Mini Apps](https://core.telegram.org/api/links#direct-mini-app-links)

Контейнер использует ту же конфигурацию. Сборка и запуск с постоянным томом для данных:

```powershell
docker build -t fit-feet-finds .
docker run --env-file .env -e HOST=0.0.0.0 -e PORT=3000 -e DATA_DIR=/app/data -p 127.0.0.1:3000:3000 -v fit-feet-data:/app/data fit-feet-finds
```
